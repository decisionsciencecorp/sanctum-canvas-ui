The OpenUI CLI can scaffold a Next.js agent application with Agent Interface, an OpenUI renderer, and a server route for model generation.

## 1. Create the application

Run the command with the self-hosted template to connect your own OpenAI-compatible provider:

```bash tab="pnpm" tab-group="pkg"
pnpx @openuidev/cli@latest create --template openui-self-hosted
```

```bash tab="bun" tab-group="pkg"
bunx @openuidev/cli@latest create --template openui-self-hosted
```

```bash tab="yarn" tab-group="pkg"
yarn dlx @openuidev/cli@latest create --template openui-self-hosted
```

```bash tab="npm" tab-group="pkg"
npx @openuidev/cli@latest create --template openui-self-hosted
```

## 2. Configure your provider key

Enter your provider key when prompted, or add it to the generated environment file:

```bash
OPENAI_API_KEY=sk-your-key-here
```

The key stays in the generated server route. Browser code calls your application and never receives this server credential.

## 3. Run

```bash tab="pnpm" tab-group="pkg"
pnpm dev
```

```bash tab="npm" tab-group="pkg"
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and request an interface such as a comparison table or interactive form.

## 4. Deploy and share your app

Once a prompt works locally, deploy to your Vercel account from the project directory. If the dev server is running, use another terminal:

```bash tab="pnpm" tab-group="pkg"
pnpx @openuidev/cli@latest deploy
```

```bash tab="bun" tab-group="pkg"
bunx @openuidev/cli@latest deploy
```

```bash tab="yarn" tab-group="pkg"
yarn dlx @openuidev/cli@latest deploy
```

```bash tab="npm" tab-group="pkg"
npx @openuidev/cli@latest deploy
```

Allowlisted keys from `.env`, such as `OPENAI_API_KEY`, are passed to the deployment.

Check the environment and access settings in Vercel: the first deployment may be production. Open the hosted URL and try the same prompt before sharing. The [deployment guide](/docs/deploy) covers key persistence, backend compatibility and the controls needed before public use.
