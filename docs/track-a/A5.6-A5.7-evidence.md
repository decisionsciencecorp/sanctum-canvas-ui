## Behavior

### Carousel (A5.6)

- Native `scroll-snap-type: x mandatory` on track; labelled Previous/Next buttons.
- Keyboard: ArrowLeft/Right, Home/End on focused track.
- Live `role="status"` announces `Slide N of M`.
- Homogeneous slide structure enforced (`enforceSlideStructure`); mismatches dropped + `data-structure-error`.
- Index / scrollLeft preserved across keyed updates that append slides.
- `prefers-reduced-motion` → `scroll-behavior: auto` + `data-reduced-motion`.

### Modal (A5.7)

- Native `<dialog>` with `showModal` / `close`.
- Accessible title via `aria-labelledby`; close control labelled.
- Initial focus on open; Tab trap; Escape + backdrop click close; body scroll lock.
- Focus restored to triggering control on close.
- Stream updates while `open: true` do **not** re-focus or close.
