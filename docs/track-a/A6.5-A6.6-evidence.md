## Behavior

### Table (A6.5)

- Column-oriented contract (`columns[]` / `Col` children) → semantic `<table><thead><tbody>`.
- Uneven column lengths pad empty cells to `max(data.length)`.
- Status: empty / error / loading / refetching (props + `ctx.query` `__openui_*` snapshot).
- Initial page size **10**; pager when more rows.
- Sort via `sortable` headers or controlled `sortBy`/`sortDir`; number display formatting.
- Keyboard-scrollable overflow (`tabindex=0` + ArrowLeft/Right/Home/End).
- **No TanStack.**

### EditableTable (A6.6)

- Cell types: text, number, date-single, select, URL.
- Stable `data-row-id` from row `id`.
- Select → edit (Enter/F2/typeahead) → commit (Enter/Tab/blur) / cancel (Escape).
- Changed-cell count vs baseline; Reset / Save Changes bar.
- Validation via `formValidation.validateField` (+ select/number rules).
- Save sends positional `{ id, values[] }` through `ctx.mutations.runMutation` (A3.6).
- URL display/href filtered with `urlPolicy.safeUrl` (A4.4).
