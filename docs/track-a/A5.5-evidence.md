## Behavior

- **Auto-reveal:** while `ctx.stream.isStreaming` (or props), each newly arrived section is opened; Steps advances `aria-current` / progress to the newest step.
- **Final collapse:** when streaming ends, SectionBlock collapses to the **first** section **only if** the user has not toggled open state.
- **Stable manual choice:** after user intervene (trigger click / `sectionUserSelect` / step title click), later chunks **never** reopen, auto-advance, or collapse against that choice.
- **Accessible progress:** Steps exposes `aria-valuenow` / `valuemax` / `valuetext` + polite status; current step has `aria-current="step"`.
- **Coordination:** filenames distinct from Tabs agent (`Tabs.js` / `Accordion.js`); no Carousel/Modal on this card.
