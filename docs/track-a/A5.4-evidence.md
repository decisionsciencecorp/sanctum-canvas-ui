## Behavior

- **Tabs:** `role="tablist"` / `tab` / `tabpanel`, roving `tabindex`, Arrow Left/Right/Up/Down, Home/End, `aria-controls` / `aria-selected`, persistent panels (all panels stay mounted; inactive `hidden`).
- **Stream:** auto-follow growing tab content until user interacts (upstream TabsRenderer).
- **Accordion:** disclosure `button` + `aria-expanded` / `aria-controls` / `role="region"`; single collapsible; auto-open newest item while streaming until user intervenes.
- **Keys:** statement `id` / item `value` keys keep selected/open state across reconciler updates; components set `ownsChildren: true` so chrome is not wiped by empty `vnode.children`.
- **Tokens:** `--canvas-*` only (no `--openui-`).
