## Behavior

- All `href`/`src` filtered with `urlPolicy.safeUrl` (default import if ctx omits policy).
- Plain list items = content only; action-bearing ListItem / FollowUpItem dispatch `continue_conversation` **only** on user click / Enter / Space.
- No dispatch while `ctx.stream.isStreaming`; messages size-bounded (`MAX_CONTINUE_CHARS = 4000`).
- CodeBlock copy uses clipboard (or execCommand fallback) and announces via `aria-live` **without** focusing the copy button.
- Image / ImageBlock require `alt` or `decorative`; unsafe/missing src and `onerror` show a textual fallback.
- CitationRef resolves 1-based indices against SourceContext; unsafe source URLs never become active links.
