## Behavior

- Flex props (`direction`, `gap`, `align`, `justify`, `wrap`) → CSS classes + `data-*` mapped to `--canvas-space-*`.
- `gap: "md"` (library default) aliases to token `m`.
- Wrap + `justify: "between"` → `start` (upstream Stack quirk).
- Children: `props.children` via `ctx.renderChildren`; `vnode.children` via A4 reconciler.
- Card regions: content (`CardContent`), sources (`CardSources` / `props.sources` partition); header left for A5.2 `CardHeader`.
- Partial: `data-openui-partial` + skeleton placeholder; `assertInteractive` blocked.
- Source URLs filtered with `urlPolicy.safeUrl` (no `javascript:` href/data-url).
